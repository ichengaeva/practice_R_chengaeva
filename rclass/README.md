# Домашнее задание

Работа выполняется командами из трёх или четырёх человек.
Координатор выполняет часть анализа, объединяет ветки и собирает итоговый отчёт.
Остальные участники работают с лабораторными данными (`lb`), витальными показателями (`vs`) и генотипированием (`gf`).
В команде из трёх человек координатор выполняет импорт данных генотипирования (раздел 1.4), а анализ 3.3 можно не выполнять.

Рекомендуемый порядок выполнения:

1. Координатор создаёт GitHub репозиторий и приглашает участников.
   Добавляет в основную ветку (`main`) папку `data` и файл `homework.qmd` и загружает на GitHub.
2. Все выполняют свою работу в ветках для разделов 1.1-1.4
3. Координатор объединяет результаты в основную ветку (`main`) и выполняет раздел 2.
4. Для раздела 3 участники создают ветки от обновлённой основной (`main`).
   Так вы не будете мешать друг другу.
5. Координатор объединяет работу участников.
6. Задания из раздела 4 лучше также выполнять в отдельных ветках.

Результатом выполненного домашнего задания будет ссылка на GitHub репозиторий команды.
Не забудьте пригласить в него [Воронина Кирилла](https://github.com/yoursdearboy/) и [Ольгу Потанину](https://github.com/Olga-Potanina).
В репозитории должны быть данные, выполненный `01-analysis.qmd` и собранный из него HTML-отчёт.
А история коммитов должна показывать работу в команде.
Помощь друг друг в команде приветствутется, как и переиспользование кода, например при помощи функций, но не повторение «в лоб».

Оцениваться будет в первую очередь правильность решения и читаемость кода.
Также обратите внимание на оформление отчета и форматирование кода.
Используйте `flextable` для оформления таблиц.
Настройте форматирование на сохранение (см. запись занятия).

В чанках приведены функции, которые могут пригодиться при выполнении заданий.
Это подсказки, а не единственный способ решения.
Можете использовать другой подход, если он даёт корректный результат.
Справку по функции можно открыть командой `?имя_функции`, например `?pivot_wider`.

И напоминаем, что в коде нужно использовать только относительные пути.
